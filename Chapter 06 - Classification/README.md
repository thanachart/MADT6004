# Chapter 06 — Classification

Predict who will respond to the comeback voucher

## Run
- **Local Jupyter** (after cloning the repo): `jupyter notebook` in `notebooks/` and open the `.ipynb`. Make sure you've cloned the full repo so that `Integrated Data Analytics Exercise/data/brewlab.db` exists alongside this folder.
- **Colab**: open the notebook via the badge below. The bootstrap cell clones the repo and installs requirements automatically.

## What you'll do
Brew Lab sent the *Comeback 50* voucher to lapsed loyalty members. Some responded; most didn't. You'll train a classifier to predict who is likely to respond — useful for targeting future campaigns.

You will:
1. Build features per customer
2. Train a logistic regression and a decision tree
3. Compare predicted probabilities
